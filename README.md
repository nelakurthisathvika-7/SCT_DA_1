# Superstore Sales Dashboard

## Task
Excel Sales Dashboard – Data Analyst Internship

## Objective
Analyze sales data and create an interactive Excel dashboard to identify sales trends, category performance, regional performance, and top-performing products.

## Dataset
Superstore Sales Dataset

## Work Completed
- Cleaned and reviewed the dataset
- Checked for duplicate records
- Reviewed missing values
- Calculated total sales
- Analyzed sales by category
- Analyzed sales by region
- Analyzed monthly sales trends
- Analyzed sales by sub-category
- Identified top 10 products by sales
- Applied conditional formatting
- Created an Excel sales dashboard

## Key Insights
- Total Sales: $2,261,536.78
- Top Category: Technology
- Top Region: West
- Top Sub-Category: Phones

## Important Note
The provided dataset does not contain a Profit field, so profit analysis was not performed.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- GitHub
